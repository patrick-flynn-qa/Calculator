# Java Basic Calculator

## Project Overview
This project is a simple command-line calculator developed in Java as part of my QA Boot Camp training.

The application allows users to enter two numbers and select a mathematical operation. It then performs the selected calculation and displays the result.

## Features
- Accepts two numerical inputs from the user.
- Supports four basic mathematical operations:
  - Addition
  - Subtraction
  - Multiplication
  - Division
- Uses conditional statements (`if`, `else if`, and `else`) to determine which operation to perform.
- Includes input validation for invalid operation selections.
- Prevents division by zero and displays an appropriate error message.

## Technologies Used
- Java 25
- Eclipse IDE
- Java Scanner Class for user input

## Java Concepts Practiced
This project demonstrates foundational Java programming concepts, including:

- Variables and data types (`double` and `int`)
- User input using the `Scanner` class
- Conditional statements (`if`, `else if`, and `else`)
- Arithmetic operators
- Nested conditional statements
- Basic input validation
- Resource management using `scanner.close()`

## How to Run
1. Clone or download this repository.
2. Open the project in Eclipse or another Java IDE.
3. Locate the `Calculator.java` file inside the `day3` package.
4. Run the application.
5. Follow the console prompts to enter two numbers and select a mathematical operation.

## Example Usage

**User Input:**
```text
Please enter the first number
10
Please enter the Second number
5
Next Please Choose an Operation
1 Addition
2 Subtraction
3 Multiplication
4 Division
4
```

**Output:**
```text
Result: 2.0
```
